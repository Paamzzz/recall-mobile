O que é o Virtual DOM e por que o React o utiliza?

RESPOSTA

É uma representação leve do DOM real em memória. O React o usa para calcular as mudanças mínimas necessárias antes de atualizar o DOM real, tornando as atualizações de UI mais eficientes.
